# AI Concierge MVP

An AI-powered concierge assistant for hospitality businesses (hotels, resorts,
short-term rentals). Answers guest questions from a business knowledge base,
captures leads, and escalates complex requests to a human.

## Status
🚧 Early development — capstone project.

## Core Features (MVP)
- Chat interface for guests
- Business knowledge base (hours, pricing, FAQs, services)
- In-session conversation memory
- Lead capture (name, email, phone, inquiry)
- Human handoff / escalation with ticket storage

## Stack
- Backend: Python, FastAPI
- Structure: `app/main.py` entrypoint, `app/routes/` (API endpoints), `app/schemas/` (Pydantic models), `app/services/` (business logic — intent detection, memory, response generation)
- Dependencies tracked in `requirements.txt`
